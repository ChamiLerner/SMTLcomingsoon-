# נפלאות הדולומיטים · יורוטריפ 2026 🏔️

אפליקציית ווב (PWA) לקבוצה — 10 מבוגרים + 7 ילדים, 15–22 ביולי 2026.
עובדת בדפדפן, נראית כמו אפליקציית טלפון, ניתנת להוספה למסך הבית ועובדת גם **בלי אינטרנט**.

## מה יש באפליקציה
- **היום** — מציג אוטומטית את היום הנכון: תמונה, מזג אוויר חי, שעת יציאה, תכנית מלאה, ארוחת ערב, לינה וניווט.
- **כל הימים** — כל שמונת ימי המסלול בכרטיסים.
- **שוברים** — פתיחת שובר ה־PDF של כל יום בלחיצה.
- **מידע** — מספרי חירום, בתי מלון, טלפוני מסעדות עם סטטוס הזמנה, ופרטי הקבוצה.
- מזג אוויר חי לכל יעד (Open-Meteo, ללא צורך במפתח).
- ניווט ב־Google Maps לכל נקודה לפי קואורדינטות מדויקות.
- ספירה לאחור עד היציאה, וסימון "היום" בזמן הטיול.
- תגית 👦 **לנוער** על פעילויות שמתאימות במיוחד לילדים.

## איך מעלים לאוויר (אתר סטטי, בלי שרת)
זהו אתר סטטי לגמרי — אין צורך ב־Node, React או מסד נתונים.
מעלים את כל הקבצים ל־root של האתר כך ש־`index.html` בשורש. עם GitHub Pages זה עולה אוטומטית.
חשוב: האתר צריך **HTTPS** כדי שהוספה למסך הבית ועבודה אופליין יעבדו.

## הוספת שוברים
שמרו כל שובר כ־PDF בשם התאריך, בתיקיית `vouchers`:
```
vouchers/2026-07-16.pdf
vouchers/2026-07-17.pdf
```
הכפתור באפליקציה יפתח אותו אוטומטית.

## עריכת התוכן
כל תוכן הטיול נמצא בקובץ אחד וקריא — **`trip-data.js`**.
כל יום הוא אובייקט אחד. אפשר לשנות טקסט, שעות, מסעדות וסטטוס הזמנה בקלות.
הימים 21–22 ביולי מסומנים `tentative:true` (תכנון ראשוני) — לעדכון כשייסגרו.
